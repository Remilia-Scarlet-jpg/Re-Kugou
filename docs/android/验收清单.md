# RE:KG Android 版 · 验收清单

> 目的:用 5~10 分钟把「只能真机/真浏览器才验得了」的部分走一遍。
> 每一步都写了**正常长什么样**和**失败时把什么发我**,你只需要照做 + 贴结果。

## 准备

```powershell
# 手机开 USB 调试并插上,确认能看见设备
& tools\platform-tools\adb.exe devices          # 应出现 xxxxxxxx  device
# 装包(或把 release\REKG-1.1.5-arm64-debug.apk 传到手机点安装)
& tools\platform-tools\adb.exe install -r release\REKG-1.1.5-arm64-debug.apk
```

建议同时开着日志,出问题时不用重来:

```powershell
& tools\platform-tools\adb.exe logcat -c        # 清空
& tools\platform-tools\adb.exe logcat -s CapacitorNodeJS:* capacitor-nodejs:* Capacitor/Console:* chromium:*
```

## A. 应用能起来(最关键)

| # | 操作 | 正常 | 失败时发我 |
| --- | --- | --- | --- |
| A1 | 点图标启动 | 先看到**暗色**启动画面(不是白屏),1~3 秒内出现界面 | 截图 + logcat 前 50 行 |
| A2 | 若停在「正在启动内置服务…」页 | 会自己重试,最多第 10 次后停下并给出提示 | 截图(能看清"第几次")+ logcat 里含 `[rekg]` 的行 |

> 兜底页出现且一直不成功 = 内置 Node 服务没起来。logcat 里若无任何 `[rekg]` 行,说明 Node 引擎本身没启动;
> 有 `[rekg] kugou api started` 但页面仍失败,说明服务起来了但没监听 3001。

## F. 回归(需要 PC + Chrome)

```powershell
# 1) 起双服务:start.bat,或
cd api; node app.js --platform=lite      # 窗口 1
cd ..;  node server.js                   # 窗口 2
# 2) 跑回归(需要未登录态)
node scripts/cdp_test.js
```

**期望**:末尾打印 `xxx/313 通过` 且 `失败 0`。重点看新增的两段:

- **S36 手机视口**(390×844 模拟):无横向溢出 / 播放条完整 / 三行堆叠 / 触控面 ≥44px / 桌词按钮隐藏
- **S37 全屏歌词**:打开关闭、标题与当前行有文本、Esc 与 ✕ 都能退

失败就把这几行贴给我 —— 都是尺寸/时序类小问题,改起来很快。
